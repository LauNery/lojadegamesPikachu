## ✨ Bem-vindo à **Loja de Games Pikachu**! ✨

Seu destino número 1 para comprar os melhores jogos e acessórios eletrônicos! Aqui, a diversão é garantida com uma experiência de compra rápida, segura e cheia de novidades. 🚀

---

## 📝 Sobre o Projeto

Imagine uma loja virtual onde você encontra tudo que precisa para jogar e se divertir — desde os clássicos até os lançamentos mais quentes! Nosso sistema foi criado para facilitar sua navegação, busca por produtos e gerenciamento de estoque. Tudo pensado para você aproveitar ao máximo!

---

## 🌟 Funcionalidades em Destaque

- 🛍️ **Cadastrar Produtos**: Adicione novos jogos, consoles ou acessórios.
- 📂 **Gerenciar Categorias**: Crie categorias como Ação, Aventura, RPG, etc.
- 🤝 **Gerenciar Fornecedores**: Cadastre seus fornecedores confiáveis.
- 🔍 **Busca Rápida**: Encontre seu jogo favorito em segundos!
- 🚚 **Cálculo de Frete**: Estime o valor do envio antes de finalizar a compra.
- 📜 **Listagem de Produtos**: Veja todos os itens disponíveis com detalhes completos.

## 🏗️ Estrutura do Projeto

### Entidades principais:

### 📦 Produto
| Campo     | Descrição                                    |
|------------|----------------------------------------------|
| nome       | Nome do jogo ou produto                      |
| descricao  | Detalhes sobre o produto                     |
| preco      | Valor do produto                             |
| frete      | Valor do frete ou informações de envio      |
| fornecedor | Quem fornece o produto                        |
| origem     | País ou região de origem                     |

### 🗂️ Categoria
| Campo | Descrição                        |
|---------|----------------------------------|
| nome    | Nome da categoria (exemplo: Ação) |
